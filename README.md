# CostoStock App 📦

Aplicación móvil Android diseñada para la gestión de inventario y compra/venta de productos excedentes mediante geolocalización. 

## 🛠 Arquitectura y Tecnologías
*   **Entorno de desarrollo:** Android Studio
*   **Lenguaje:** Kotlin
*   **Interfaz:** Jetpack Compose (Material Design 3)
*   **Arquitectura:** MVVM (Model-View-ViewModel) + Repository 
*   **Base de Datos Local:** SQLite (Room)
*   **Navegación:** Jetpack Navigation Compose

## 🚀 Características Principales
*   Sistema de Login y Registro con validación Regex.
*   Encriptación de contraseñas mediante SHA-256.
*   Navegación dinámica entre perfiles de usuario.
*   Gestión de base de datos asíncrona con Corrutinas.
*   Geolocalización.
